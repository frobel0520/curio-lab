## 1. 摘要

「好奇一下 Curio Lab」是面向繁體中文使用者的生活小工具母站，把日常「一直有點想知道的事」做成打開就能用、結果好分享的輕量互動工具。目前實際上線兩個工具：「主子帳本」（養貓終身費用試算器）與「16 型貓格」（20 題情境式貓咪人格測驗）。

## 2. 目標使用者

- 台灣與繁體中文圈對生活趣味題目感興趣的讀者。
- 想評估養貓開銷的潛在飼主，以及喜歡在社群分享寵物測驗結果的貓奴。

## 3. 目標與成功標準

| 目標 | 成功標準 |
|---|---|
| 打開即用、免登入 | 無需註冊登入，所有試算與測驗於瀏覽器端完成，進度自動暫存於 `localStorage` |
| 可分享的結果圖卡 | 結果頁可於前端 Canvas 繪製 1080 × 1350 圖卡，支援直接下載、Web Share 與社群分享 |
| 短期雲端分享連結 | 使用者主動選擇產生分享連結時，可寫入 7 天自動過期的雲端卡片，並能顯示 OpenGraph 預覽 |
| 零月費營運 | 前端靜態資源與後端分享 Worker 皆嚴格限制於 Cloudflare 免費額度內，超額時自動降級為純本機下載／分享 |
| 效能與安全標頭 | 通過 CI 驗證、靜態輸出與正式站 CSP／安全標頭稽核 |

## 4. 範圍

### 4.1 已實作範圍（現況）

- **母站與隱私頁**：首頁（`/`）工具入口與隱私說明頁（`/privacy`）。
- **主子帳本（`/tools/cat-cost`）**：Landing 頁、8 步驟互動試算精靈（`/calculator`，含台灣市場預設金額與自訂輸入）、結果頁（`/result`，總開銷／月均／日均與 Canvas 分享圖卡）、計算方法頁（`/methodology`）、常見問題頁（`/faq`）。
- **16 型貓格（`/tools/cat-personality`）**：Landing 頁、20 題情境測驗（`/quiz`，含 16 題雙軸題與 4 題校準題）、結果頁（`/result`，對應 16 張 WebP 插畫與 Canvas 分享圖卡）。
- **雲端分享 Worker（`worker/`）**：提供 7 天 TTL 的分享圖卡暫存與 OpenGraph 頁面（`/s/:id`、`/i/:id.png`），含每日／每月寫入、讀取與容量硬上限，以及 Threads OAuth 發文支援（選用）。

### 4.2 明確排除

- 使用者帳號系統、長期雲端個人資料庫或跨裝置登入同步。
- 付費物件儲存（如 R2）：已於實作紀錄明確排除，避免誤觸計費風險。
- 第三方廣告或行為追蹤腳本。
